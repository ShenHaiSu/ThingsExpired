# Things Expired 前端设计规范

> 本文档定义了前端项目的视觉设计系统、样式规范和交互动效标准，用于约束 LLM 生成代码时保持样式、颜色和交互的一致性。

---

## ⚠️ LLM 自主设计前端 UI 规范

**在开始任何设计工作之前，LLM 必须明确以下设计要求：**

### 设计原则

| 规范项       | 要求            | 说明                                   |
| ------------ | --------------- | -------------------------------------- |
| **多端适配** | 移动端 + 桌面端 | 所有界面设计必须同时考虑移动端和桌面端 |
| **交互设计** | 双端完整        | 交互逻辑必须在两端都完整设计           |
| **样式设计** | 双端适配        | 样式必须适配不同屏幕尺寸               |
| **落地标准** | 双端完成        | 两端界面设计都完成才允许开发落地       |

### LLM 设计流程要求

```
┌─────────────────────────────────────────────────────────────────┐
│                      LLM 界面设计流程                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 需求分析阶段                                                 │
│  ├── 理解功能需求                                                │
│  ├── 确定目标用户                                                │
│  └── 分析双端使用场景                                            │
│                                                                 │
│  2. 设计阶段                                                     │
│  ├── 移动端界面设计（375px基准）                                  │
│  ├── 桌面端界面设计（1440px基准）                                 │
│  ├── 响应式断点设计                                              │
│  └── 交互逻辑设计（双端）                                        │
│                                                                 │
│  3. 验收阶段                                                     │
│  ├── 移动端界面完整性检查 ✓                                      │

│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 双端 UI 设计规范

#### 移动端设计规范 (375px基准)

| 规范项   | 要求                               | 说明                           |
| -------- | ---------------------------------- | ------------------------------ |
| **布局** | 单列布局，垂直滚动                 | 避免横向滚动，内容优先展示     |
| **导航** | 底部导航栏或汉堡菜单               | 常用功能放在底部，易于单手操作 |
| **交互** | 触摸友好，按钮最小点击区域 44x44px | 避免误触，提供足够的触摸反馈   |
| **字体** | 正文不小于 14px，标题适当放大      | 确保在小屏幕上可读性           |
| **间距** | 适当增加间距，避免拥挤             | 提供足够的呼吸空间             |
| **图片** | 自适应宽度，高度自适应             | 避免图片变形                   |

#### 桌面端设计规范 (1440px基准)

| 规范项   | 要求                         | 说明                   |
| -------- | ---------------------------- | ---------------------- |
| **布局** | 多列布局，灵活利用空间       | 可以并排显示更多信息   |
| **导航** | 顶部导航栏或侧边栏           | 提供更丰富的导航选项   |
| **交互** | 鼠标友好，悬停效果           | 提供视觉反馈           |
| **字体** | 正文 14px-16px，标题适当放大 | 确保在大屏幕上舒适阅读 |
| **间距** | 适当增加间距，保持视觉层次   | 避免内容过于密集       |
| **图片** | 固定宽度或自适应             | 保持视觉一致性         |

### 双端 UI 设计限制

| 限制项         | 要求                                         | 说明                             |
| -------------- | -------------------------------------------- | -------------------------------- |
| **颜色使用**   | 必须使用项目定义的绿色系，禁止使用蓝色和紫色 | 保持视觉一致性                   |
| **组件选择**   | 优先使用 PrimeVue 组件，保持组件风格统一     | 避免自定义组件导致样式不一致     |
| **响应式策略** | 必须遵循移动端优先原则，渐进增强             | 确保在所有设备上都有良好的体验   |
| **交互一致性** | 双端交互逻辑必须一致，避免功能差异           | 确保用户在不同设备上有一致的体验 |
| **性能考虑**   | 设计时考虑加载性能，避免过度动画和复杂布局   | 确保应用流畅运行                 |

## 2. 设计原则

### 1.1 核心原则

| 原则         | 说明                               | 实践要求                           |
| ------------ | ---------------------------------- | ---------------------------------- |
| **一致性**   | 整个应用保持统一的视觉语言         | 所有页面使用相同的颜色、字体、间距 |
| **层次感**   | 通过颜色、大小、对比度建立信息层次 | 重要信息使用主色，次要信息使用灰色 |
| **简洁性**   | 减少不必要的视觉元素               | 每个元素应有明确的存在理由         |
| **可访问性** | 确保所有用户都能使用               | 颜色对比度符合 WCAG 2.1 标准       |
| **多端适配** | 移动端和桌面端同等重要             | 双端设计必须同时完成               |

### 2.1 核心原则

| 原则         | 说明                               | 实践要求                           |
| ------------ | ---------------------------------- | ---------------------------------- |
| **一致性**   | 整个应用保持统一的视觉语言         | 所有页面使用相同的颜色、字体、间距 |
| **层次感**   | 通过颜色、大小、对比度建立信息层次 | 重要信息使用主色，次要信息使用灰色 |
| **简洁性**   | 减少不必要的视觉元素               | 每个元素应有明确的存在理由         |
| **可访问性** | 确保所有用户都能使用               | 颜色对比度符合 WCAG 2.1 标准       |
| **多端适配** | 移动端和桌面端同等重要             | 双端设计必须同时完成               |

### 2.2 设计决策

- **UI 框架**: PrimeVue 4.x + Tailwind CSS 4.x
- **主题模式**: 浅色主题为主，支持深色主题扩展
- **圆角风格**: 中等圆角 (6px-10px)，保持柔和感
- **阴影风格**: 柔和投影，增加层次感但不喧宾夺主
- **响应式策略**: 移动端优先，渐进增强

## 3. 颜色系统

### 2.1 主色板

项目使用 **绿色系** 作为主色调，禁止使用蓝色和紫色。以下是核心颜色变量：

```scss
// 核心颜色变量 - 请勿修改这些值
:root {
  // 主色 - 绿色系 (禁止使用蓝色 #3b82f6 和紫色)
  --primary-50: #dcfce7; // 浅绿背景
  --primary-100: #bbf7d0;
  --primary-200: #86efac;
  --primary-300: #4ade80;
  --primary-400: #22c55e;
  --primary-500: #16a34a; // 主色 - 深绿色
  --primary-600: #15803d; // 主色悬停
  --primary-700: #166534; // 主色按下
  --primary-800: #14532d;
  --primary-900: #0f3622;

  // 语义颜色
  --color-primary: var(--primary-500);
  --color-primary-hover: var(--primary-600);
  --color-primary-active: var(--primary-700);
}
```

### 2.2 语义颜色

| 用途     | 颜色变量                 | Hex 值    | 使用场景                     |
| -------- | ------------------------ | --------- | ---------------------------- |
| 主色     | `--color-primary`        | `#16a34a` | 按钮、链接、选中状态         |
| 成功     | `--color-success`        | `#16a34a` | 成功提示、正常状态           |
| 警告     | `--color-warning`        | `#f59e0b` | 警告提示、即将过期           |
| 危险     | `--color-danger`         | `#ef4444` | 错误提示、删除操作、已过期   |
| 信息     | `--color-info`           | `#14b8a6` | 信息提示（使用青色替代蓝色） |
| 文字主色 | `--text-color`           | `#1f2937` | 标题、正文                   |
| 文字次色 | `--text-color-secondary` | `#6b7280` | 描述、辅助文字               |
| 边框色   | `--surface-border`       | `#e5e7eb` | 输入框、卡片边框             |
| 背景色   | `--surface-ground`       | `#f9fafb` | 页面背景                     |
| 卡片背景 | `--surface-card`         | `#ffffff` | 卡片、弹窗背景               |

### 2.3 状态颜色

```typescript
// 物品状态颜色映射
const statusColors = {
  1: { label: '正常', color: 'success', bg: '#bbf7d0', text: '#14532d' }, // 深绿色
  2: { label: '已过期', color: 'danger', bg: '#fee2e2', text: '#991b1b' }, // 红色
  3: { label: '已消耗', color: 'info', bg: '#ccfbf1', text: '#0f766e' }, // 青色（替代蓝色）
}

// 过期提醒颜色映射
const expireColors = {
  expired: { bg: '#fee2e2', text: '#dc2626', icon: 'pi pi-exclamation-triangle' }, // 已过期 - 红色
  critical: { bg: '#fef3c7', text: '#d97706', icon: 'pi pi-exclamation-circle' }, // 明天过期 - 黄色
  warning: { bg: '#ffedd5', text: '#ea580c', icon: 'pi pi-clock' }, // 即将过期 - 橙色
  normal: { bg: '#bbf7d0', text: '#15803d', icon: 'pi pi-check-circle' }, // 正常 - 深绿色
}
```

### 2.4 LLM 使用颜色规则

```vue
<!-- ✅ 正确：使用 CSS 变量或 Tailwind 预设颜色 -->
<template>
  <button class="bg-green-500 hover:bg-green-600">确认</button>
  <span class="text-green-600">成功</span>
  <div class="bg-red-50 text-red-700">错误信息</div>
  <div class="bg-teal-50 text-teal-700">信息提示</div>
</template>

<!-- ❌ 错误：禁止使用蓝色、紫色或未定义的硬编码颜色 -->
<template>
  <button style="background-color: #3b82f6">确认</button>
  <!-- 禁止：蓝色 -->
  <button style="background-color: #8b5cf6">确认</button>
  <!-- 禁止：紫色 -->
  <span style="color: #1890ff">成功</span>
  <!-- 禁止 -->
</template>
```

### 2.5 禁止的颜色

以下颜色**禁止**在前端项目中使用：

| 颜色类型     | 禁止的 Hex 值                                            | 原因             |
| ------------ | -------------------------------------------------------- | ---------------- |
| 蓝色系       | `#3b82f6`, `#1890ff`, `#2563eb`, `#1d4ed8`, `#60a5fa` 等 | 与绿色主题不协调 |
| 紫色系       | `#8b5cf6`, `#7c3aed`, `#6d28d9`, `#5b21b6` 等            | 与绿色主题不协调 |
| 蓝色相关语义 | 信息提示使用 `#06b6d4`（已改用 `#14b8a6` 青色）          | 统一使用绿色系   |

### 3.2 字号规范

| 用途     | 变量                  | 字号             | 行高 | 字重 |
| -------- | --------------------- | ---------------- | ---- | ---- |
| 大标题   | `--font-size-h1`      | 32px (2rem)      | 1.2  | 700  |
| 标题     | `--font-size-h2`      | 24px (1.5rem)    | 1.3  | 600  |
| 小标题   | `--font-size-h3`      | 20px (1.25rem)   | 1.4  | 600  |
| 正文     | `--font-size-body`    | 14px (0.875rem)  | 1.5  | 400  |
| 小字     | `--font-size-small`   | 12px (0.75rem)   | 1.5  | 400  |
| 辅助文字 | `--font-size-caption` | 11px (0.6875rem) | 1.4  | 400  |

### 3.3 Tailwind 字号映射

```vue
<!-- 正确使用字号 -->
<template>
  <h1 class="text-2xl font-bold">大标题</h1>
  <!-- 24px -->
  <h2 class="text-xl font-semibold">标题</h2>
  <!-- 20px -->
  <h3 class="text-lg font-semibold">小标题</h3>
  <!-- 18px -->
  <p class="text-base">正文内容</p>
  <!-- 16px -->
  <p class="text-sm">正文</p>
  <!-- 14px -->
  <p class="text-xs">辅助文字</p>
  <!-- 12px -->

```

### 3.4 多端字号适配

```vue
<!-- 响应式字号 -->
<template>
  <!-- 移动端较小，桌面端较大 -->

  <!-- 正文保持一致 -->
  <p class="text-sm md:text-base">正文内容</p>

  <!-- 辅助文字移动端更小 -->
  <span class="text-xs md:text-sm">辅助信息</span>
</template>
```

## 5. 间距系统

### 4.1 基础间距

项目使用 4px 作为基础单位：

| 名称 | 变量            | 数值 | 使用场景             |
| ---- | --------------- | ---- | -------------------- |
| xs   | `--spacing-xs`  | 4px  | 标签内边距、图标间距 |
| sm   | `--spacing-sm`  | 8px  | 组件内部紧凑间距     |
| md   | `--spacing-md`  | 16px | 组件之间标准间距     |

```vue
<!-- 错误1: 使用蓝色 -->

<div class="bg-green-500">...</div>

<!-- 错误2: 使用紫色 -->
<div class="bg-purple-500">...</div>
<!-- 修正：使用绿色 -->
<div class="bg-green-500">...</div>

<div class="w-[300px]">...</div>
<!-- 修正 -->
<div class="w-80">...</div>

<!-- 错误4: 过度动画 -->
<Button class="animate-spin animate-bounce">...</Button>
<!-- 修正 -->
<Button>...</Button>

<div class="my-custom-button">...</div>
<!-- 修正 -->
<Button>...</Button>
```
