# Assets 目录说明

此目录存放应用资源文件。

## 必需文件

- `icon.ico` - 应用图标文件

## 图标要求

- 格式: ICO
- 尺寸: 建议包含 16x16, 32x32, 48x48, 64x64, 128x128, 256x256 多种尺寸
- 用途: 
  - 应用窗口图标
  - 系统托盘图标
  - Windows通知图标

## 如何生成图标

1. 使用在线工具如 https://icoconvert.com/ 或 https://convertio.co/
2. 从PNG图片转换为ICO格式
3. 确保包含多种尺寸以适应不同场景

## 注意事项

如果暂时没有图标文件，可以:
1. 使用默认的WPF窗口图标
2. 从前端项目的favicon.ico复制并转换
